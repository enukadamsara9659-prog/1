# AETHERFALL — Cradle of Ash

> ☄️ **උල්කාපාතයෙන් පටන් ගන්න open‑world squad action RPG** — three.js + WebGL2, 100% browser, 100% CC0 assets.
> A meteor breaks apart in the dawn sky, falls, and fills an 8 km × 8 km continent with
> shard-born monsters. You land with a squad of three and push back.

---

## Run it

```bash
npm install
npm run assets     # downloads CC0 sources and bakes public/assets (≈73 MB) — only needed once
npm run dev        # http://localhost:5173
npm run build      # production bundle into dist/
node tools/headless-smoke.mjs   # headless logic test (no GPU needed)
```

`public/assets/` is a generated folder (kept out of git). `scripts/fetch-sources.sh`
sparse-clones the CC0 source kits and `scripts/build-assets.mjs` converts them into
web-ready GLB / packed textures.

## What is in the game

| System | Status | Notes |
|---|---|---|
| **Meteor intro cinematic** | ✅ | ~35 s, skippable: the meteor enters, breaks into 8 fragments, impacts, dust plume, then the camera settles on your squad |
| **World** | ✅ | 2049² heightfield, 8 km × 8 km, hydraulic erosion, rivers, roads, 40+ POIs (villages, temple, palace, monastery, outpost, ruins, camp, shrine) |
| **Terrain / water / sky** | ✅ | GPU-raymarched terrain with 8 blended PBR layers, triplanar cliffs, Gerstner ocean + flowing rivers, analytic sky + volumetric clouds, day/night |
| **Structures** | ✅ | Procedural architecture merged per-material + Kenney kits, interior floors, colliders, bridges |
| **Vegetation** | ✅ | 70 k+ instanced trees/rocks, streamed undergrowth, wind shader, trunk collision grid |
| **Player** | ✅ | Third/first person, sprint, slide, dodge roll, vault, swim, stamina, shield, ADS, recoil, camera collision |
| **Weapons** | ✅ | 5 firearms + aether blade, per-weapon stats, levels, **unlimited ammo** (magazines still reload) |
| **Combat** | ✅ | Hitscan with spread/bloom/falloff, headshots, tracers, decals, particles, grenades, aether pulse, melee |
| **Enemies** | ✅ | 5 procedural rigs (spawnling, brute, spitter, wraith, titan), nest population streaming, steering/LOS AI, LOD |
| **Squad** | ✅ | Mira (marksman), Dorn (bulwark), Nyx (engineer) — follow/hold/focus, revive you, banter |
| **Quests** | ✅ | 5 main + 3 side, objective types (goto/kill/collect/destroy), journal, rewards |
| **Progression** | ✅ | Levels, 5 skill trees (20 skills), weapon XP, shards, aether |
| **World objects** | ✅ | Crash site, shard nests, fast-travel beacons, supply caches, NPCs, loot drops |
| **UI** | ✅ | HUD, minimap + compass, world map with fast travel, inventory, skills, journal, settings, pause, death |
| **Audio** | ✅ | Fully synthesised WebAudio: weapon layers, impacts, creatures, procedural reverb, adaptive score |
| **Save** | ✅ | localStorage autosave every 90 s + manual save |

## Controls

| Key | Action | Key | Action |
|---|---|---|---|
| `W A S D` | Move | `LMB` / `RMB` | Fire / Aim |
| `Shift` | Sprint | `R` | Reload |
| `Ctrl` / `C` | Crouch / slide | `1–4`, wheel | Swap weapon |
| `Space` | Jump / vault, `A·D·S`+Space = dodge | `F` | Aether blade |
| `E` | Interact / revive | `Q` / `G` / `H` | Pulse / grenade / stim |
| `V` | First ↔ third person | `Z` / `X` / `B` | Squad follow / hold / focus |
| `M` / `Tab` | World map | `I` / `K` / `J` | Loadout / skills / journal |
| `Esc` | Pause | | |

## Asset credits

* **Kenney** (CC0) — fantasy town, castle, graveyard, survival props, nature & mini-forest kits.
* **Kenney / Poly Pizza** — stylized nature pack.
* **three.js examples** — Soldier, Xbot, Michelle, RobotExpressive characters; PBR textures.
* **ambientCG** (CC0) — surface materials.
* Everything else (creatures, weapons materials, audio, procedural textures) is generated by this project.

## Layout

```
src/

  world/       worldgen (+worker), terrain, water, sky, vegetation, structures, world objects
  entities/    player, character rig, squad, enemies, procedural creatures
  combat/      weapon definitions, hitscan/projectiles/explosions
  cinematics/  the meteor intro
  fx/          post-processing, particles, tracers, decals
  game/        quests, skill trees, save
  ui/          HUD, menus, styles
tools/         headless smoke test
```
